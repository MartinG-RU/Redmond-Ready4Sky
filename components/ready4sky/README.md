# ready4sky

Этот компонент управляет BLE и используется всеми драйверами архива. Локальная установка по SMB описана в [LOCAL-INSTALL.md](../../LOCAL-INSTALL.md), конфликты и ограничения безопасности — в [главном README](../../README.md).

`time_id` должен ссылаться на источник времени ESPHome. Дополнительные настройки вкладываются в `scan_parameters`:

```yaml
ready4sky:
  time_id: r4s_clock
  scan_parameters:
    duration: 30s   # допустимо 1–3600 с
    interval: 150ms # допустимо 3–10240 мс
    window: 50ms    # допустимо 3–10240 мс, не больше interval
    active: true
    monitor: false  # true: вывод обнаруженных устройств в лог
```

Продолжительность сканирования должна быть не менее трёх интервалов. При включённом `monitor` в логах появляются обнаруженные устройства; не включайте его постоянно без необходимости.

Физическая работа BLE, поиск, reconnect, безопасность авторизации и все варианты временных зон в этой переработке не проверены на устройствах.
