# skydew

Драйвер увлажнителей RHF-3310S, RHF-3317S, RHF-3318S и RHF-3320S. Работа этих моделей с данной версией не испытывалась на приборах. Укажите основной `ready4sky` как описано в [главном README](../../README.md), затем добавьте, например:

```yaml
skydew:
  - mac_address: AA:BB:CC:DD:EE:04  # замените на реальный адрес
    model: RHF-3317S                # замените на точную модель
    informing:
      humidity:
        name: Влажность
      temperature:
        name: Температура увлажнителя
      signal_strength:
        name: RSSI увлажнителя
    controlling:
      power:
        name: Увлажнитель
      target_humidity:
        name: Целевая влажность
```

`humidity` и `power` обязательны. Доступность дополнительных режимов зависит от модели и проверяется схемой. Сборка не подтверждает фактический диапазон или реакцию конкретного увлажнителя.
