# skysmoke

> Этот компонент не должен быть единственным каналом пожарной безопасности. Физический датчик с исправленной версией не испытывался.

После установки основного `ready4sky` можно добавить:

```yaml
skysmoke:
  - mac_address: AA:BB:CC:DD:EE:03  # замените на реальный адрес
    model: RSS-61S                  # или RFS-HSS001
    informing:
      smoke:
        name: Дым
      temperature:
        name: Температура датчика дыма
      battery_level:
        name: Батарея датчика дыма
      signal_strength:
        name: RSSI датчика дыма
```

`smoke` обязателен, остальные сущности необязательны. При потере связи показания переводятся в недоступное состояние; это не означает, что дыма нет. Формула температуры сохранена из upstream, достоверность показаний и работы при возгорании аппаратно не подтверждена. См. [основной README](../../README.md).
