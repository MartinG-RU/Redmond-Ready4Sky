# skycoffee — кофеварки Ready4Sky

> Физические кофеварки с этой исправленной версией не испытывались. Исходный автор сообщал о проверке RCM-M1509S, RCM-M1519S/RFS-KCM002 и RCM-M1525S; в этой копии эти заявления не подтверждены. Испытывайте работу под наблюдением и не используйте кофеварку как устройство аварийной автоматики.

При использовании локальной папки путь и порядок установки приведены в [LOCAL-INSTALL.md](../../LOCAL-INSTALL.md). Добавьте в существующую конфигурацию ESP32 компонент `ready4sky` и, например:

```yaml
skycoffee:
  - mac_address: AA:BB:CC:DD:EE:01  # заменить на Bluetooth MAC кофеварки
    model: RCM-M1519S               # заменить на точную модель
    informing:
      signal_strength:
        name: Кофеварка RSSI
      # Только для RCM-M1519S/RFS-KCM002 и RCM-M1525S:
      energy:
        name: Кофеварка энергия
      work_cycles:
        name: Кофеварка циклы
      work_time:
        name: Кофеварка время работы
    controlling:
      power:
        name: Кофеварка
      lock:
        name: Кофеварка блокировка
      strength:
        name: Кофеварка крепость
```

`mac_address`, `model`, `controlling` и `controlling.power` обязательны. Блок `informing` и его датчики необязательны. `energy` публикуется в kWh, `work_time` — в часах; счётчики получены из протокола и не сверялись с приборами.

* `lock` и `strength` разрешены для типов RCM-M1509S, RCM-M1519S/RFS-KCM002 и RCM-M1525S; `buzzer` — только для RCM-M1509S и её перечисленных вариантов.
* `energy`, `work_cycles` и `work_time` реализованы только для RCM-M1519S/RFS-KCM002 и RCM-M1525S. Несовместимая настройка отклоняется во время проверки YAML.
* В ветке RCM-M1508S/RCM-1508S и RCM-M1505S код не читает байт блокировки. Исправление позволяет попытку включения после первого статуса, а не считает начальное значение `0xFF` постоянной блокировкой. Реакция и защита именно этих моделей требуют проверки; не предполагайте, что ПО контролирует их физические блокировки.
* Список точных принимаемых названий содержится в `MODEL_TYPE` файла `__init__.py`. По одному наличию имени нельзя судить о проверенной поддержке модели. При потере связи состояние может остаться последним полученным; подтверждайте состояние на самом приборе.

Полный шаблон для YAML в `/config/esphome` — [coffee-in-esphome-root.yaml](../../examples/coffee-in-esphome-root.yaml). До использования замените примерные адреса, модель и секреты.
